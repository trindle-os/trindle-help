# Contributing

Thank you for taking an interest in Trindle Help. It is appreciated.

The way this project is set up, the code is written and kept in one place, so code changes from outside cannot be taken. That has nothing to do with the quality of anyone's work. It works best when we hear what went wrong and fix it ourselves.

So the most useful thing you can send is a description:

- **Something broken or wrong in a page?** Report it on the [Buildmorphic community](https://trindle.buildmorphic.com) first; GitHub issues are also welcome. Say which page, what you did, what you expected and what you saw. The version of Trindle helps. A picture of the window is welcome.
- **A page that is missing or unclear?** Say what you were trying to do and where the help let you down. You do not need to write the fix.
- **A security problem?** Please use private reporting rather than a public issue. [SECURITY.md](SECURITY.md) explains how.
